# Alex Prins — Dallas REALTOR®

Premium editorial real-estate website built with Vite + React.

## Hosting

The source is maintained in the private GitHub repository `kamssofficial/Alexprins`. GitHub Pages deployment is configured through `.github/workflows/deploy-pages.yml`.

Expected hosted URL: https://kamssofficial.github.io/Alexprins/

## Local-only status

This site is not published through Manus. GitHub Pages is the requested hosting destination.

## Run locally

```bash
npm install
npm run dev
```

## Content/data notes

- Demo property cards are explicitly labeled `DEMO PROPERTY` and do not represent live MLS inventory.
- Historical addresses are labeled `PAST TRANSACTION`.
- No testimonials, awards, license numbers, sale prices, or personal biography details were invented.
- The consultation form is a demo flow until connected to a real scheduling/CRM service.
- The property assistant only presents verified site topics and does not claim to know live listings.
