# Alex Prins — Dallas REALTOR®

Premium editorial real-estate website concept built locally with Vite + React.

## Local-only status

This build is intentionally **not published through Manus**. It is a local working copy in the private GitHub repository `kamssofficial/Alexprins`.

## Run locally

```bash
npm install
npm run dev
```

## Content/data notes

- Demo property cards are explicitly labeled `DEMO PROPERTY` and do not represent live MLS inventory.
- Historical addresses are labeled `PAST TRANSACTION`.
- No testimonials, awards, license numbers, sale prices, or personal biography details were invented.
- The consultation form is a demo flow until connected to a real scheduling/CRM service.
- The property assistant only presents verified site topics and does not claim to know live listings.
